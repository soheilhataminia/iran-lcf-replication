# Data and code

Replication materials for **Iran’s sustainability gap under sanctions: An ARDL-ECM analysis of the load capacity factor**, **PLOS Sustainability and Transformation**.

- **DOI:** https://doi.org/10.1371/journal.pstr.0000192
- **Data:** https://doi.org/10.7910/DVN/5V06YD
- **Code:** https://doi.org/10.5281/zenodo.19297890
- **Coverage:** Iran, annual data, 1965–2024
- **Software:** EViews 13

## Run

1. Save the `.prg` file in a writable folder.
2. Open it in EViews and select **Run**.
3. Confirm that `LCF_STATUS.csv` reports **SUCCESS**.
